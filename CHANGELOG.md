## v0.1.0 — unreleased

Initial development release.

### Added

- `toji index`: content-hashed incremental indexing of Python / TS / TSX / JS codebases into a SQLite graph (symbols, signatures, docstrings, call/import/contains/inherits edges).
- Evidence commands: `map`, `find`, `calls`, `callers`, `deps`, `read`, `blast` (BFS blast radius), `stats`.
- Import-aware symbol resolution with explicit ambiguity and unresolved-call reporting.
- Rich text output for humans, stable JSON (`--json`) for agents.
- Installable skill for agent ecosystems (`SKILL.md`, `npx skills add`).
